# Guide vendeur - Fidélys Chez Sénan

> Toutes les actions du quotidien en moins de 30 secondes.

---

## Connexion au dashboard

URL : `https://[votre-domaine]/admin/login`
Identifiants transmis par ON AGENCY.

---

## 1. Inscrire un nouveau client

1. Menu > **Nouveau client**
2. Saisir le nom complet et le numéro de téléphone
3. Cliquer **Inscrire le client**
4. Le lien de la carte s'affiche : cliquer **WhatsApp** pour l'envoyer directement
5. Le client clique sur le lien, sa carte s'ouvre dans son navigateur

> Voir section "Message WhatsApp" en bas de ce guide pour le texte à envoyer.

---

## 2. Enregistrer un achat

### Mode recommandé : scan QR

1. Menu > **Enregistrer un achat**
2. Le client affiche son QR code depuis sa carte
3. Cliquer **Scanner QR**, pointer la caméra sur l'écran du client
4. Le profil client s'identifie automatiquement
5. Saisir le montant de l'achat en FCFA
6. Cliquer **Valider l'achat**
7. Le client reçoit une notification push de confirmation

### Mode secours : recherche par téléphone

1. Sélectionner l'onglet **Rechercher par téléphone**
2. Saisir les premiers chiffres du numéro
3. Sélectionner le bon client dans la liste
4. Saisir le montant et valider

---

## 3. Génération automatique des bons

Les bons sont calculés automatiquement, sans action de votre part.

- Palier : **500 000 FCFA** cumulés
- Bon offert : **50 000 FCFA**, valable **150 jours**
- Le client est notifié sur son téléphone dès qu'un bon est généré
- Le code à 6 caractères s'affiche sur sa carte (bouton "Révéler")

---

## 4. Valider un bon client

1. Menu > **Valider un bon**
2. Le client révèle le code à 6 caractères depuis sa carte et vous le dicte
3. Saisir le code dans le champ prévu
4. Le solde du bon s'affiche (montant disponible, date d'expiration)
5. Saisir le montant à débiter (utilisation partielle possible)
6. Cliquer **Valider ce montant**

---

## 5. Envoyer une campagne push

1. Menu > **Campagnes**
2. Saisir le titre et le message (aperçu visible en temps réel à droite)
3. Ajouter un lien optionnel si nécessaire
4. Cliquer **Préparer l'envoi** puis confirmer
5. Tous les clients ayant activé les notifications reçoivent le message

---

## 6. Modifier les paramètres de la boutique

Menu > **Paramètres**

- Nom de la boutique (affiché sur toutes les cartes clients)
- Couleur principale de l'interface client
- Palier d'achat pour débloquer un bon
- Montant du bon offert
- Durée de validité du bon (en jours)

Les modifications sont appliquées immédiatement pour tous les clients.

---

## Message WhatsApp pour les nouveaux clients

Copier et coller ce texte dans WhatsApp après avoir inscrit le client, en remplaçant `[PRENOM]` et `[LIEN]` :

```
Bonjour [PRENOM] ! Bienvenue chez Sénan.

Voici votre carte de fidélité digitale :
[LIEN]

Cliquez sur le lien depuis votre téléphone.
Installez l'application : bouton "Ajouter à l'écran d'accueil" dans votre navigateur.
Autorisez les notifications pour recevoir vos bons directement.

A chaque tranche de 500 000 FCFA d'achats cumulés, vous recevez automatiquement un bon de 50 000 FCFA à utiliser chez nous. Bonne fidélité !
```

> Le bouton **WhatsApp** dans le dashboard pré-remplit le message avec le lien du client.
